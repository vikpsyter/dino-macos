# 🐍 Классическая Змейка для Терминала macOS (Terminal Snake)

Красочная и увлекательная игра "Змейка" с Emoji-графикой, работающая прямо в терминале вашего Mac без установки каких-либо сторонних библиотек.

---

## 🌟 Особенности игры

- 🚀 **Работает "из коробки"**: Использует стандартные встроенные библиотеки Python (`curses`), никакого `pip install`!
- 🎨 **Emoji-графика**: Голова 🐍, тело 🟩, еда 🍎, препятствия 🪨.
- 📐 **Игровое поле 40x40**: Оптимизированная фиксированная сетка.
- 🌀 **Сквозные стены**: Змейка проходит сквозь края экрана и появляется с противоположной стороны!
- 🪨 **Динамические препятствия**: Камень спавнится случайным образом при поедании яблок.
- ⚡ **4 режима сложности**:
  1. *Легкий (Easy)* — комфортная скорость, мало препятствий.
  2. *Средний (Medium)* — сбалансированная скорость.
  3. *Хардкор (Hardcore)* — высокая скорость и частые препятствия.
  4. *Динамический (Dynamic)* — скорость игры растет по мере вашего счета.
- 🏆 **Таблица рекордов (Топ-10)**: Сохранение результатов и имени игрока в файл `high_scores.json`.
- 🔄 **Быстрый перезапуск**: Возможность мгновенно переиграть (`R` или `Enter`) после проигрыша.

---

## 🎮 Управление

| Действие | Клавиши |
|---|---|
| **Движение** | Стрелки (⬆️ ⬇️ ⬅️ ➡️) или **W / A / S / D** |
| **Пауза / Продолжить** | **P** или **Пробел** |
| **Выход из игры / меню** | **Q** |
| **Перезапуск после Game Over** | **R** или **Enter** |
| **В главное меню** | **M** |

---

## 🚀 Как запустить

1. Откройте Терминал на вашем Mac (`Terminal.app` или `iTerm2`).
2. Перейдите в папку с игрой:
   ```bash
   cd /path/to/dino-macos
   ```
3. Запустите игру одной командой:
   ```bash
   python3 snake.py
   ```

> ⚠️ **Важно**: Для комфортной игры в 40x40 клеток разверните окно Терминала пошире.
